# ИИ Тренер — приложение

Разбор движений по камере в реальном времени и в записанном видео: 33 точки тела, подсчёт повторов, голосовые подсказки, итог подхода. Всё считается на устройстве.

Открывается в браузере телефона и внутри Telegram-бота [@ii_trener_ak_bot](https://t.me/ii_trener_ak_bot).

Версия 2.5.3: разгибания ног считаются по последовательным циклам одной видимой ноги, без ожидания неподвижной калибровки и возврата к самому первому углу. Начальное более глубокое сгибание не объединяет рабочую серию в один повтор. Добавлены сглаживание, защита от коротких скачков точек и дрожания на удержании; пропуск рабочих суставов прерывает незавершённый цикл. Результат видео постоянно показывает число повторов и подходов, включая несколько подходов в записи; при потерях трекинга или расхождении счётчиков остаётся предупреждение. Личные видео и координаты в репозиторий не включены. Проверка на компьютере не заменяет проверку в Safari на iPhone.

Полная проверка, включая непрерывную серию разгибаний, старт во время движения, дрожание, пропуски и итог видео: `node --test --test-timeout=20000 tests/*.cjs`. Нейросеть на реальной записи проверяется отдельно от этих синтетических тестов.

Версия 2.5.2: отменённые кадры камеры и видео не могут попасть в другое упражнение или восстановить закрытый анализ. Повторяющаяся техническая ошибка модели показывается отдельно от отсутствия распознанных повторов. Зафиксирован один тариф 490 ₽ в месяц; расширенный блок 290 ₽ отложен, разовый пакет убран. Планируемая оплата — Т-Банк, налоговый режим по вводным владельца — УСН «доходы» 6%. Эквайринг не подключён, оплата остаётся выключенной. Приоритет — проверка распознавания на реальных записях из тренажёров.

Версия 2.5.1: исправлена подготовка в тренажёрах. Разгибанию ног достаточно таза, колена и стопы одной ноги; голова, руки и дальняя сторона тела не блокируют счёт. Для суставных углов 3D не требуется восстанавливать ось по двум плечам или двум тазобедренным суставам. После устойчивой подготовки счёт включается автоматически, калибровка сохраняется. Если анализа нет, показывается причина и доступен счёт без оценки техники; при остановке — повторный разбор записи или ручной ввод. Распознанные повторы сохраняются перед сменой упражнения. Резервный счётчик разгибаний следит за коленом и не считает движения рук. Добавлены синтетические проверки 20°, 30°, 45°, закрытой головы/рук, загрузки видео и восстановления результата при неустойчивом 3D. Реальное видео из тренажёра всё ещё нужно для проверки качества самой нейросети.

Версия 2.5: бесплатный локальный анализ MediaPipe 3D. Камера и загруженные видео используют `keypoints3D` в метрах; пиксельные точки остаются для рисования скелета. Суставные углы рассчитываются по трём координатам, остальные сигналы — в системе координат тела с учётом поворота к камере. Для приседа высота таза привязана к стопам, поскольку начало world-координат MediaPipe находится в центре таза. Проверки глубины и наклона дополнены наблюдаемым сведением коленей и боковым смещением.

Работает съёмка спереди, сзади, сбоку и под углом при достаточной видимости суставов. Телефон должен стоять ровно и неподвижно. Низкая уверенность, повреждённые точки и пропуски кадров более 0,5 с прерывают незавершённый повтор и требуют новой калибровки. Если модель с самого начала не возвращает 3D-точки, явно показывается прежний 2D-режим с ограничениями ракурса. После появления 3D потеря world-точек не переключает анализ на 2D посреди подхода.

3D по одной камере — предварительная оценка. Скрытые суставы, контакт пяток с полом, нагрузка на суставы и положение оборудования не определяются надёжно; 3D-результаты сохраняются с этой пометкой и без общей оценки «чистая техника». Telegram v2 получает только число повторов без оценки; подробные предварительные подсказки сохраняются в веб-приложении. Нужны модели и статический HTTPS-хостинг для доступа с телефона; вычислительный сервер, GPU в облаке и платные API для анализа не нужны. После загрузки библиотек и моделей возможно использование их офлайн-кеша браузера.

Описание выходов модели: [MediaPipe Pose Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker), [адаптер TFJS BlazePose/MediaPipe](https://github.com/tensorflow/tfjs-models/blob/master/pose-detection/src/blazepose_mediapipe/detector.ts). Используется уже поставляемый с приложением BlazePose; переход на другой SDK не требуется.

Версия 2.4.1: личный тестовый доступ по отдельному промокоду без квот и срока окончания. Активируется в профиле и сохраняется на устройстве; обычные пробные и тестовые квоты сохраняются. Подбор программ, импорт фото, камера и видео доступны без лимитов.

Версия 2.4: импорт нескольких тренировочных дней по заголовкам и повторному началу нумерации, подтверждение числа дней, рекомендации тренера отдельно от упражнений. На проверке можно разделять и объединять дни, переносить упражнения, менять вес и повторы, добавлять и удалять строки, отменять правки. Черновик сохраняется на устройстве. Уже загруженную программу можно исправить кнопкой «Исправить распределение по дням» на вкладке «Программа».

Проверки: `node --test tests/regression.cjs tests/camera-flow.cjs tests/import-program.cjs tests/pose-3d.cjs` (Node.js, без установки зависимостей). Тесты импорта используют искусственные результаты OCR, включая 12 фото на 3 дня; качество чтения конкретных скриншотов проверяется отдельно. Тесты 3D проверяют присед, отжимание, сгибание и подъём рук с восьми направлений камеры, разрыв трекинга, испорченные точки, переключение 2D/3D, время планки, обработку записанного видео и перенос результата в дневник. Это искусственные скелеты и имитация декодирования, без запуска нейросети. Точность MediaPipe и пороги подсказок необходимо отдельно проверить на реальной съёмке с целевых телефонов до публичного запуска.
