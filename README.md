# ИИ Тренер — приложение

Разбор техники приседа и отжиманий по камере в реальном времени: 33 точки тела, подсчёт повторов, голосовые подсказки, итог подхода. Всё считается на устройстве.

Открывается в браузере телефона и внутри Telegram-бота [@ii_trener_ak_bot](https://t.me/ii_trener_ak_bot).

Версия 2.4.1: личный тестовый доступ по отдельному промокоду без квот и срока окончания. Активируется в профиле и сохраняется на устройстве; обычные пробные и тестовые квоты сохраняются. Подбор программ, импорт фото, камера и видео доступны без лимитов.

Версия 2.4: импорт нескольких тренировочных дней по заголовкам и повторному началу нумерации, подтверждение числа дней, рекомендации тренера отдельно от упражнений. На проверке можно разделять и объединять дни, переносить упражнения, менять вес и повторы, добавлять и удалять строки, отменять правки. Черновик сохраняется на устройстве. Уже загруженную программу можно исправить кнопкой «Исправить распределение по дням» на вкладке «Программа».

Проверки: `node --test tests/regression.cjs tests/camera-flow.cjs tests/import-program.cjs` (Node.js, без установки зависимостей). Тесты импорта используют искусственные результаты OCR, включая 12 фото на 3 дня; качество чтения конкретных скриншотов проверяется отдельно. Тесты камеры проверяют сценарии и состояние приложения на искусственных данных; точность MediaPipe проверяется отдельно на реальной съёмке.
