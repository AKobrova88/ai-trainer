# ИИ Тренер — приложение

Разбор техники приседа и отжиманий по камере в реальном времени: 33 точки тела, подсчёт повторов, голосовые подсказки, итог подхода. Всё считается на устройстве.

Открывается в браузере телефона и внутри Telegram-бота [@ii_trener_ak_bot](https://t.me/ii_trener_ak_bot).

Версия 2.3: безопасный просмотр примера, улучшения двух тем, дневник по месяцам, проверка числового ввода, упрощённый тестовый доступ и подготовка кадра перед подходом. В режиме счёта повторов оценка техники не выставляется.

Проверки: `node --test tests/regression.cjs tests/camera-flow.cjs` (Node.js, без установки зависимостей). Тесты камеры проверяют сценарии и состояние приложения на искусственных данных; точность MediaPipe проверяется отдельно на реальной съёмке.
